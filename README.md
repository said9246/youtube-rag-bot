# YouTube RAG Bot 🚀

An AI-powered YouTube chatbot using LangChain, RAG, and Hugging Face to answer questions from video transcripts.

## 🌐 Live Demo

Try the application here: [YouTube RAG Bot](https://youtube-rag-bot-9mccxzfzkc4xvemkea9vxf.streamlit.app/)

## 🛠️ Technologies Used

- Python
- LangChain
- Retrieval-Augmented Generation (RAG)
- Hugging Face
- Streamlit
- Vector Database
